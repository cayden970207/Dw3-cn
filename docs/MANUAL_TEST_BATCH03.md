# 第三批人工测试

仅在本机使用已生成的测试 CUE：`local/font-recovery/p1-batch03-v2/DW3-p1-batch02.cue`。对应镜像 SHA-256 为 `389de62b2455a30431ea3acb340843060550f9f1cd58fbf645af9f824ac31c6f`。保留原始 ZIP、原镜像及已有样板，不要覆盖。

使用 `local/font-recovery/p1-batch03-fixture-v1/memcard1.mcd` 的**新副本**作为模拟器独立记忆卡，切勿直接覆盖原存档或夹具。这个存档经人工设置为有一个卡包、10,000 BIT、第一张商店卡已有九张，用来测试条件分支；它不是自然游玩进度。更换模拟器后先确认所选记忆卡确实是副本。本轮自动运行证据来自 PCSX-Redux/OpenBIOS，DuckStation 仍待单独核对。

1. 从测试 CUE 冷启动，通过游戏内读档选择记忆卡 1 和第一个存档槽。前往飞鸟卡牌竞技场的卡牌商店。
2. 选择购买卡片，选择第一张卡。确认显示 10,000 BIT、该卡数量为 9，并出现「已持有九张」；关闭提示并返回商店。
3. 选择打开卡包，确认出现「选择卡包」。取消并重进；选择卡包后确认开包画面可以切换卡片并返回。开包会消耗测试副本中的卡包，重复测试请重新复制夹具。
4. 如需复测存读档，在开包前取消回商店，前往旅馆存档；完全退出模拟器，再从同一测试 CUE 冷启动并游戏内读档，回商店重复步骤 2、3。使用的仍是独立记忆卡副本。
