# 卡片图鉴标题样板：人工复测

仅适用于已生成的本地测试副本。原始镜像 SHA-256 `c7130c532f42d7c01f393bf067b073a1e4b924607a71e2287b0c3792468777fc`；本轮样板 SHA-256 `afdb58042d8060a9523305f18a3e35e6841089d903248ba8ebd2408302b7e433`。副本的 BIN 和同名 CUE 在本机 `local/font-recovery/run-20261107/card_album_test/`，不要上传游戏镜像或记忆卡。建议使用独立模拟器配置和新记忆卡，或先复制自己的存档以免影响原件。

1. 在模拟器加载样板 CUE。启动语言界面后选「中文」，按 START 确认。
2. 新游戏推进到取得卡片盒（卡牌竞技场柜台的介绍剧情结束），或使用已有卡片盒的**存档副本**。在场景按 START 打开菜单，向下选择第六项进入队伍界面，在队伍界面选择第一项进入卡片图鉴。
3. 等待图鉴完全显示，检查左上标题为「卡片图鉴」，四个字清晰、没有裁切或与右边文字重叠；检查卡片页面及翻页仍正常。原版对应标题是英文。需要比较时，原/样板截图仅保存在本机的 `runtime-album-before-long/run/` 和 `runtime-album-after/run/` 目录。
4. 按返回键退出图鉴，检查回到队伍界面；进入卡组界面并返回，再回到场景。随后在可保存处用**存档副本**保存，重启并读档，重新打开图鉴确认标题仍正常。
5. 如出现黑屏，请先等待加载完成；记录模拟器和 BIOS 版本、复现步骤及现象。不要用黑屏、跳帧或仅凭启动成功代替画面确认。

本轮自动回放已验证第 1–3 步的标题显示及第 4 步的返回路径；新存档和读档发生在访问图鉴之前。翻页以及访问图鉴后的再次存读档仍待人工验证。该清单不代表整个游戏已完成汉化或通过全流程测试。
