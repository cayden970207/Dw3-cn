# P1：私有文本回写（仅限验证过的编码字节）

此步骤仅在**真实欧版汉化镜像、字形编码映射、实际控制码和替换内容都已经验证**后执行。现在的公开仓库尚未恢复用户镜像的这些信息，因此本说明是后续可重复执行的工程流程，不是现成的汉化补丁。

## 1. 生成镜像指纹与本地索引

```sh
python tools/scan_text_tables.py "/path/to/数码宝贝世界3 欧版汉化.zip" \
  --private-dump local/real-scan.json
```

用户的私有 `local/real-scan.json` 包含每条原始文本的 `raw_hex`、`offset_bytes`、`raw_sha256`，以及所属文本文件的 `lba`。这些是改动时的精确前置条件，属于游戏原始数据，**绝不能上传到公开 GitHub**。

## 2. 建立本地人工审查清单

```sh
python tools/triage_english.py local/real-scan.json \
  --queue local/english-candidates.json
```

候选字形解析可能误报，必须逐条校对。确认原汉化中文字库编码和实际窗口边界，再将译文转换为游戏原生字节。

## 3. 编写私有补丁清单

仅作结构示例，下面所有值都是占位符、**不是游戏真实数据**：

```json
{
  "schema_version": 1,
  "source_image_sha256": "<替换成实际镜像64位小写SHA256>",
  "changes": [
    {
      "file_id": 17,
      "table": null,
      "index": 1,
      "original_sha256": "<实际扫描记录中的raw_sha256>",
      "replacement_hex": "<经过中文字库校验的字节十六进制，末尾必须00>"
    }
  ]
}
```

每条 `file_id/table/index` 必须与扫描结果精确一致。只支持在原字符串字节容量内缩短或等长修改，不增加条目、不重排文本指针，不自动增加换行/分页，控制码及参数必须保持原样。

## 4. 生成一个全新镜像供测试

```sh
python tools/apply_text_bytes.py \
  "/path/to/数码宝贝世界3 欧版汉化.zip" \
  local/reviewed-edit.json \
  local/dw2003-edited.bin
```

脚本会重新扫描输入，校验 SHA-256，检查每个改动在原始表中的位置、编码和控制码，再按扇区回写全新镜像。如果是 2352 字节的 CD-XA Mode 2 Form 1 扇区，会先验原 EDC/ECC，再计算新 EDC/ECC；其它扇区类型拒绝修改。最后重新读取整个文本目录：除指定条目外，其他条目必须保持完全一致。

成功输出仅表明结构性回写验证，**不是模拟器运行通过**。如某个被原汉化改写的扇区原本校验码不正确，工具会拒绝操作而不是偷偷修补。

## 5. 实机确认才算一个阶段完成

- 使用指定模拟器/核心与固定设置启动；
- 验证截图中的每字、行宽、分页及游戏动作；
- 对比两个选项、角色名字、不同道具/数值等动态边界；
- 真正执行写档和读档，并记录能否从存档继续；
- 从**原始**汉化镜像复现新增版本；
- 通过实际游戏测试后，才生成小型增量补丁（`tools/byte_patch.py`）并审查能否合规公开分享。

## 非目标

目前没有可以根据 Unicode 中文自动生成 `replacement_hex` 的可信转换器；这个工具不提供中文字库和画面渲染支持，不承诺零 Bug，也不发布游戏原镜像。源镜像、输出镜像、私有字库、字节清单、存档均在 Git 忽略目录保存。
