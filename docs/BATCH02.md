## 可直接运行的目录检查

```sh
python3 tools/check_batch02.py
python3 -m unittest discover -s tests -v
```

第一条只读取仓库 JSON，不需要再扫描 ZIP，不写任何镜像。
退出码 1 表示生成了有效的待处理报告、仍禁止写入；2 表示数据自相矛盾。
输出实时计算缺字并拒绝重复改动第一批、源条目哈希错配和窗口上下文错配。
其中 `new_playable_entries: 0` 表示**该目录检查本身**没有制作补丁；已完成条目及其运行证据由单独的第二批报告记录。
即使以后全部字形已经确认，也不会因此解除文字终审、容量、排版和游戏测试要求。
条件性字节数和推进距离只按两字节汉字、12 像素步进、无控制码估算，不代表实际窗口通过。
