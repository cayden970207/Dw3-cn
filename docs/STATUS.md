## 欧版原版新字库实验分支（2026-11-07）

`experiment/eu-original-new-font` 从现有成果 `c1f876d` 开始，使用用户另行提供的欧版原版，未替换下文的原汉化基线。已按 Ark Pixel 优先生成并逐格校验 32,950 个 12×12 字形；字体来源、覆盖范围和本机字库见 `docs/EU_FONT_EXPERIMENT.md`。由于 Ark Pixel 自身缺字，使用 Fusion Pixel、Noto Sans CJK SC 和 GNU Unifont 补充。附带的 48px 对照图是离线样图，不是 DuckStation 高清替换包。

新建的欧版测试副本只把字库中的四字「卡片图鉴」放入实验字位：实际游戏中打开、退出、重开及 1～27 页翻页均已观察；访问后使用独立卡存档，退出模拟器后从测试 CUE 冷启动、游戏内读档并再次显示标题也已验证。保存及冷读使用独立记忆卡副本，详细范围和模拟器提示见 `reports/SHARE_THIS_eu_font_save_regression_report.json`。该测试暂借了四个欧版日文字位，只能证明这个受限样机，不能证明其他语言安全。

为检查「槽」的可辨度，另以独立样机在图鉴标题展示「记忆插槽」，对比同一字形的 11px 和 12px 推进；12px 在字符间形成一列空白。该对照未改变真实记忆卡界面，也未在其他窗口验证。见 `reports/SHARE_THIS_eu_glyph_spacing_report.json`。

**整套字库还未接入游戏。** 13,084 条真实欧版文本完成新编码提案的离线原字节回环，但原游戏不能识别提案；更长文字的表指针已在内存中重建，尚未写回或运行。实际图鉴回放的 329 个堆采样均没有足够大的当前连续空闲块来直接容纳紧凑整库；缓存释放和更广场景未测试。游戏端解码、字形缓存、显存/内存、全部场景的排版和高清纹理替换仍待实现与验证。按用户条件，尚未开始声称或批量开展全游戏汉化。详见 `docs/EU_FONT_EXPERIMENT.md` 和 `reports/SHARE_THIS_eu_font_runtime_report.json`。

## 测宽与剩余阻碍

对实际 font 1、palette 0、非缩放、比例字宽路径，离线工具从真实 EXE 度量和真实纹理计算绘制步进与墨迹边界；图鉴标题、商店及卡组窗口的预测边界与真实截图一致。游戏旧测宽按旧扩展字表处理汉字：例如「卡片图鉴」实际绘制推进 48 像素，而静态模拟游戏测宽得到 22 像素。已验证的这些固定窗口不调用该测宽结果；不能由此推断其他窗口、字体、居中或动态排版安全。**通用写回封锁保持生效。**

中英混排、数字、标点、空格、动态插入及显式换行已有真实条目的离线测量。研究所进化表另以实际插入的数码兽名称完成了一次运行画面核对，推进 72 像素、墨迹 `[20,25,91,36)`；旧测宽静态模拟 44 像素，而该窗口实际 measured_width 为 0。除报告中明确列出的画面外，其窗口裁切、动态上限和运行显示仍待验证。五个扩展 token 和一个 fallback 的资源、条目、场景及条件对白调用链已定位，原字节仍在本机，含义和实际触发均 unresolved，不能当作损坏。见 `reports/SHARE_THIS_layout_validation_report.json` 和 `reports/SHARE_THIS_unknown_tokens_report.json`。
