# 第四批人工测试

在本机使用 `local/font-recovery/p1-batch04-v2/DW3-p1-batch02.cue`，对应镜像 SHA-256 `632d62e803a31fe9887c8733925663493205512dd9f1a332336c6ae1fd4849bb`。保留原 ZIP、镜像和此前各批副本。

先把 `local/font-recovery/p1-batch03-fixture-v1/memcard1.mcd` 复制成全新的独立记忆卡，并在模拟器中明确指定这个副本。夹具有 10,000 BIT、一个卡包、目标卡 59 一张；这是构造的测试条件，不是自然游玩存档。不要使用或覆盖用户原存档，也不要直接在夹具上保存。

1. 从本批 CUE 冷启动，通过游戏内读档进入第一个存档。前往飞鸟卡牌竞技场的卡牌商店；确认商店中的三角图标后显示「返回」，可按三角退出并重新进入。
2. 进入买卡，将光标向右移动五格，选中价格 1,000 BIT 的第六张卡。确认购买选择显示「买」「不」；选择「不」，确认仍有 10,000 BIT 且该卡一张。重新选卡并选「买」，确认余额 9,000 BIT、该卡两张，再返回。
3. 选择打开卡包，确认选择画面有「选择卡包」和三角「返回」；取消并重新进入，打开卡包后确认显示「卡包已打开」和三角「返回」，切换下一张并退出。开包会消耗此记忆卡副本的卡包；重复测试请重新复制夹具。
4. 打开卡组，进入编辑界面，确认右上三角图标旁的「返回」，并退出至队伍页面。
5. 若复测本批访问后的存读档：在独立卡上完成以上访问后前往旅馆由游戏存档，完全关闭模拟器，从本批 CUE 冷启动并通过游戏内读档，回到上述界面核对。此步骤是本批尚未执行的 `runtime_pending`，不能把此前批次的存读档结果当成本批通过。
